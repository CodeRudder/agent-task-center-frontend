# 任务模板管理页面

## 功能说明

任务模板管理页面用于创建、编辑、查看和使用任务模板，提高任务创建效率。

## 功能特性

### 1. 模板列表
- 显示所有任务模板
- 支持按名称和描述搜索
- 显示模板基本信息：名称、描述、优先级、标签、创建时间
- 分页显示

### 2. 模板创建/编辑
- **基本信息**
  - 模板名称（必填）
  - 模板描述（必填）

- **任务字段配置**（可选）
  - 默认标题
  - 默认描述
  - 默认优先级（低/中/高/紧急）
  - 默认分类
  - 默认标签（多个标签用逗号分隔）
  - 默认截止日期

### 3. 模板操作
- **预览**：查看模板详细配置
- **使用**：从模板创建新任务（待实现跳转）
- **编辑**：修改模板配置
- **删除**：删除模板（需确认）

## 路由

- 路径：`/templates`
- 菜单位置：任务模板

## API 接口

页面调用以下后端API：

- `GET /api/v1/templates` - 获取模板列表
- `GET /api/v1/templates/:id` - 获取模板详情
- `POST /api/v1/templates` - 创建模板
- `PUT /api/v1/templates/:id` - 更新模板
- `DELETE /api/v1/templates/:id` - 删除模板
- `POST /api/v1/templates/:id/create-task` - 从模板创建任务
